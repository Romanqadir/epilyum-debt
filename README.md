# Epilyum — سیستەمی فرۆشتن، قیست و خەرجی

سیستەمێکی ناوخۆیی بۆ بەدواداچوونی ئامێرە فرۆشراوەکان، قیستە مانگانەکان، و خەرجییەکان.

| ڕۆڵ | چی دەکات |
|---|---|
| **بەڕێوەبەر (rasty)** | کلینیک زیاد دەکات و دەستکاری دەکات، ئامێری کڕدراو و کۆی نرخ و پێشەکی تۆمار دەکات، هەموو کۆکراوەکان دەبینێت، Excel داگرتن |
| **بەکارهێنەر (sana)** | لە لیستی کلینیکەکان هەڵدەبژێرێت و پسوڵەی مانگانە تۆمار دەکات، خەرجی تۆمار دەکات |

بەکارهێنەر **ناتوانێت** کلینیک زیاد بکات — تەنیا لەوانە هەڵدەبژێرێت کە بەڕێوەبەر خستوونیەتە ناو سیستەمەوە.

**تەکنەلۆژیا:** React (Vite) · Tailwind CSS · MUI DataGrid · Supabase · Vercel

---

## چۆن کاردەکات

```
بەڕێوەبەر                          بەکارهێنەر
─────────                          ──────────
کلینیک زیاد دەکات
  └─ کڕین (ئامێرەکان)
       ├─ کۆی نرخ      23,000$
       └─ پێشەکی        8,000$
            ↓
        ماوە 15,000$  ──────────►  پسوڵەی مانگانە 1,000$
                                     ├─ بەروار، نرخی ئاڵوگۆڕ
                                     ├─ دۆلار / دینار / هەردووک
                                     └─ درا بە: کاک ئیبۆ | د. ڕاستی | خەرجی
                                          ↓
                                    ماوە 14,000$
```

ئەوەی دەچێتە **خەرجی**، دەبێتە سندوقی خەرجی. هەر خەرجییەک لەو سندوقە کەم دەکاتەوە.

بڕی **ماوە** هەرگیز پاشەکەوت ناکرێت — هەمیشە لە `کۆی نرخ − پێشەکی − قیستەکان` دەژمێردرێت.
ئەگەر پاشەکەوت بکرایە، هەر جارێک قیستێک دەستکاری یان سڕایەوە ژمارەکان لەیەکتر جیا دەبوونەوە.

## هەنگاوی ١ — نوێکردنەوەی داتابەیس

بچۆ بۆ Supabase → **SQL Editor → New query**، ناوەڕۆکی `supabase/schema.sql` بلکێنە و **Run** لێبدە.

> ⚠️ ئەم فایلە خشتە کۆنەکان (`payments`, `debts_contracts`, `transactions`) **دەسڕێتەوە** و لە
> جیاتییان پێکهاتەی نوێ دروست دەکات. کلینیکەکان و بەکارهێنەرەکان دەمێننەوە.

خشتە نوێیەکان:

| خشتە / ڕوو | چی تێدایە |
|---|---|
| `clients` | کلینیکەکان — تەنیا بەڕێوەبەر دەینووسێت |
| `sales` | هەر کڕینێک: ئامێرەکان، کۆی نرخ، پێشەکی |
| `payments` | هەر قیستێک، لەگەڵ `allocation` (ئیبۆ/ڕاستی/خەرجی) |
| `expenses` | خەرجییەکان |
| `sale_balances` | ڕوو: وەرگیراو و ماوەی هەر کڕینێک، بە دراوی خۆی |
| `client_balances` | ڕوو: کۆی هەر کلینیکێک، دۆلار و دینار بە جیا |
| `expense_fund` | ڕوو: سندوقی خەرجی — یەک ڕیز بۆ هەر دراوێک |

دڵنیابوونەوە:

```sql
select table_name, table_type
from information_schema.tables
where table_schema = 'public'
order by table_name;
```

دەبێت ٨ ئەنجام بێت (٥ خشتە + ٣ ڕوو).

## هەنگاوی ٢ — کارپێکردن

```bash
cd epilyum-debt
npm install
npm run dev
```

فایلی `.env` لەناو زیپەکەدایە. ئەگەر لە پڕۆژەیەکی تردا بەکاری دەهێنیت:

```
VITE_SUPABASE_URL=https://xxxx.supabase.co
VITE_SUPABASE_ANON_KEY=sb_publishable_...
```

بەڕێوەبەر:

```sql
update public.profiles set role = 'admin' where email = 'rasty@epilyum.com';
```

## نرخی ئاڵوگۆڕ

بە هەمان شێوەی فۆڕمی کاغەزی نووسراوە: **١٥٠,٠٠٠ دینار = ١٠٠ دۆلار**.
هەموو کۆکراوەکان بە دۆلارن، بۆیە دۆلار و دینار پێکەوە کۆدەکرێنەوە.

هەر قیستێک نرخی ئاڵوگۆڕی خۆی هەڵدەگرێت، بۆیە گۆڕانی نرخ لە داهاتوودا
ژمارە کۆنەکان ناگۆڕێت.

---

## دراو — هیچ گۆڕینێک ئەنجام نادرێت

هەر کڕینێک بە **یەک دراو** تۆمار دەکرێت: دۆلار یان دینار. پاشان هەموو شتێکی
پەیوەست بەو کڕینە — پێشەکی، هەموو قیستێک، و ئەوەی ماوە — بە هەمان دراو دەمێنێتەوە.

بۆیە ئەگەر ئامێرێک بە ٤٥,٠٠٠,٠٠٠ دینار بفرۆشرێت، ماوەکەشی بە دینار پیشان دەدرێت.
ئەگەر پێشەکییەکە بە دۆلار بێت، ماوەکە بە دۆلارە.

هیچ نرخێکی ئاڵوگۆڕ لە هیچ شوێنێکدا نییە. لە کۆکراوەکاندا، دۆلار و دینار
**بە جیا** کۆدەکرێنەوە و هەرگیز لەگەڵ یەکتر کۆناکرێنەوە — نە لە کارتەکان،
نە لە خشتەکان، نە لە Excel.

خانەکانی پارە ژمارەکان بە خۆکاری دابەش دەکەن: `45000000` دەبێتە `45,000,000`
لە کاتی نووسیندا. دینار بێ کەسر، دۆلار بە دوو کەسر.

---

## پێشەکی و ئامێری دیاری

**پێشەکی** بە هەمان دراوی کڕینەکەیە. تۆمار دەکرێت **درا بە کێ** — کاک ئیبۆ یان
د. ڕاستی. سندوقی خەرجی لێرە هەڵبژاردە نییە، چونکە ئەو سندوقە تەنیا لە قیستە
مانگانەکانەوە پڕ دەبێتەوە.

**ئامێری دیاری:** تەنیا **UPS** و **Hydra** دوگمەی «دیاری»یان هەیە، چونکە تەنیا
ئەوان بە خۆڕایی دەدرێن. ئامێری دیاری هیچ نرخێک زیاد ناکات — لە کۆی «ئامێری
فرۆشراو» نایەت، هیچ بەشێک لە نرخەکە وەرناگرێت، بەڵام لە هەموو شوێنێک بە سەوز
پیشان دەدرێت.

لانیکەم یەک ئامێر دەبێت فرۆشراو بێت — کڕینێک کە هەمووی دیاری بێت قبوڵ ناکرێت،
چونکە ئەوکات نرخێک نییە کە قیستی بۆ بدرێت.

## شار و ئامێرەکان

١٨ شار و ١٤ ئامێر (٩ ئامێری Epilyum، RF، Pelovra، Cervera، UPS، Hydra) لە
`src/lib/constants.js` دان،
و لە داتابەیسدا بە `check constraint` پارێزراون.

ئامێری نوێ = گۆڕانکاری لە **هەردوو شوێن**: `constants.js` و `constraint devices_are_known`.

## دیزاین

ڕەنگە سەرەکییەکان: `#071a44` بۆ پێکهاتە، `#27478d` بۆ هەر شتێک کە کلیکی لێدەکرێت،
`#a4c0ff` بۆ ئەو شوێنانەی چاو دەبێت بیانبینێت. ڕەنگە بێلایەنەکانیش بەرەو هەمان
ڕەنگ لاردراونەتەوە، بۆیە هیچ خاکستەرییەک بێگانە نییە.

فۆنت: **IBM Plex Sans Arabic** بۆ کوردی، **IBM Plex Sans** بۆ ژمارەکان — یەک
خێزانی فۆنت بۆ هەردوو نووسین. ژمارەکان هەمیشە `tabular` و لە ڕاستەوخۆ (LTR) دان،
بۆیە لە ستوونێکدا لەژێر یەکدا ڕیز دەبن.

ڕووکار: مێنیوی لاتەنیشت (لە RTL لای ڕاست) بە چوار بەشەوە بۆ بەڕێوەبەر و دووان بۆ
بەکارهێنەر. لەسەر مۆبایل و تابلێت دەبێتە شریتێکی سەرەوە.

## داگرتنی Excel

هەر بەشێک دوگمەی **داگرتنی Excel**ی هەیە. فایلەکە ڕێکخراوە:

- سەرەوەی هەر پەڕەیەک شریتێکی سەرمەی تاریک بە ناونیشانەوە، و لەژێری پاڵاوتنەکان و کاتی دەرهێنان
- سەردێڕەکان بە ڕەنگی شین و سپی، چەسپاو (freeze) بۆیە لە کاتی سکڕۆڵدا نامێننەوە
- هێڵەکان یەک لە دوو جیاواز بۆ خوێندنەوەی ئاسانتر، لەگەڵ چوارچێوەی باریک
- ژمارەکان بە فۆڕماتی دراو (`$#,##0.00`)، نەک دەق
- ڕیزی **کۆی گشتی** لە کۆتایی، بە ڕەنگی جیاواز
- پەڕەکان بە RTL دەکرێنەوە، لەگەڵ `AutoFilter` لەسەر سەردێڕەکان

ئەمە بە **ExcelJS** دروست دەکرێت نەک SheetJS — نوسخەی خۆڕایی SheetJS ناتوانێت
ستایل بنووسێت، بۆیە فایلەکانی ڕووتن. ExcelJS تەنیا لە کاتی داگرتندا بار دەکرێت،
بۆیە قورسییەکەی ناکەوێتە سەر کردنەوەی یەکەمی بەرنامەکە.

## نسبەی کارمەندان

جۆری خەرجی **نسبە** جیاوازە: کاتێک هەڵدەبژێردرێت، لیستی کارمەندەکان دەردەکەوێت و
دەبێت یەکێکیان دیاری بکرێت. ئەو ناوە لەگەڵ خەرجییەکەدا پاشەکەوت دەکرێت.

لە داشبۆردی **بەڕێوەبەر** → خەرجییەکان، پانێڵی **نسبە بەپێی کارمەند** پیشان دەدات
هەر کارمەندێک چەند نسبەی وەرگرتووە و کۆی بڕەکەی چەندە، بە هەردوو دراوەوە.
دوگمەی **داگرتنی نسبە** فایلێکی Excel-ـی جیا دەدات بە دوو پەڕەوە: کۆی هەر
کارمەندێک، و لیستی وردی هەموو نسبەکان.

لیستی کارمەندەکان لە `src/lib/constants.js` دایە (`EMPLOYEES`).

## داگرتنی PDF بۆ قیستەکان

لە داشبۆردی بەڕێوەبەر، کلیک لەسەر کلینیکێک → بەشی **قیستە وەرگیراوەکان**.
لەوێ پاڵاوتنی مانگ و دوگمەی **داگرتنی PDF** هەیە.

PDF-ەکە بە مانگ پۆلێن دەکرێت، بە کۆی هەر مانگێک، لەگەڵ ژمارەی پسوڵە، بڕ،
درا بە کێ، و تێبینییەکان. ئەگەر دکتۆرێک داوای «هەموو ئەوەی لە شەش مانگی
ڕابردوو دامە» بکات، **هەموو مانگەکان** هەڵبژێرە و داگرتن لێبدە.

**بۆچی دیالۆگی چاپکردن دەکرێتەوە:** jsPDF ناتوانێت پیتی کوردی بەیەکەوە
ببەستێتەوە — پیتەکان لێک جیا دەبنەوە و ئاراستەکە هەڵدەگەڕێتەوە. لەبری ئەوە،
ڕاپۆرتەکە دەدرێت بە وێبگەڕ خۆی، کە کوردی بە تەواوی ڕەندەر دەکات. لە دیالۆگەکەدا
**Save as PDF** هەڵبژێرە. دەقەکەش هەڵبژاردنی لێدەکرێت، نەک وێنە بێت.

## دوو خاڵی تەکنیکی

**پسوڵەکە PNG-ە، نەک PDF.** jsPDF بە بنەڕەت پیتی کوردی بە دروستی ناخوێنێتەوە.
پسوڵەکە وەک HTML ڕەندەر دەکرێت و بە `html-to-image` دەکرێتە وێنە — کە ئەوەشە کە
لە واتسئاپدا دەنێردرێت.

**مێژوو لە دیالۆگدایە، نەک هێڵی فراوانبوو.** `getDetailPanelContent` تەنیا لە
MUI DataGrid Pro بەردەستە. کلیک لەسەر هێڵێک دیالۆگێک دەکاتەوە.
